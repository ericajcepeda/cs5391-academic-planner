## Team 2 - Academic Planner 
The Academic Planner is part of the Student Success Hub, which is implemented as a module of Texas State University’s CS 5391 class.
This tool will be designed to help fast-tracked online students plan their assignments and deadlines through a web-based, easy-to-use tool.

## Features
- Eight-week academic planner
- Assignment creation, editing, and tracking
- Displaying upcoming and past due deadlines
- Storing completed tasks locally within the web browser
- Designing the interface for accessibility

## Development Approach
The project uses the Agile methodology with three development sprints.
